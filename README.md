### Hey, I'm Sajith 👋

Final year AI & DS student from Coimbatore.
I build AI things that work — not just notebooks that run once.

Most of my time goes into RAG systems, LLM agents, and
figuring out why a model behaves weirdly in production.
I've cut API costs by 70%+ with semantic caching,
shipped real-time trajectory prediction with multi-sensor fusion,
built tutoring systems that actually stay in-syllabus,
and made a voice AI that scores you before you finish talking.

Obsessed with **eval-driven development** — if you can't
measure it, you don't know if it works.
Occasionally I win hackathons too.
